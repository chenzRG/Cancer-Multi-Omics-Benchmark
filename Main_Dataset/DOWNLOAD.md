# Main Dataset

The MLOmics dataset is hosted on Hugging Face and can be downloaded by running the following command from the **project root directory**:

```bash
./download.sh
```

This will clone the dataset repository and place `Main_Dataset/` in the current directory.

**Direct link:** https://huggingface.co/datasets/AIBIC/MLOmics

> **Note:** The dataset uses Git LFS. Make sure `git-lfs` is installed before running the download script.
> ```bash
> # macOS
> brew install git-lfs
> # Ubuntu/Debian
> sudo apt install git-lfs
> ```
